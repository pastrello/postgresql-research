# Registro de pesquisa

Cada experimento deve começar em `ideas/` e terminar documentado em `accepted/` ou `rejected/`.

Um registro mínimo deve conter:

- hipótese;
- componente do PostgreSQL;
- motivação;
- mudanças realizadas;
- benchmark/testes;
- resultados;
- regressões;
- conclusão.

Resultados negativos são importantes e devem ser preservados em `rejected/` para evitar repetir experimentos sem evidência nova.
