# Patches experimentais

Diretório para patches exportados ou documentação associada a alterações isoladas.

Categorias iniciais:

- `security/`
- `planner/`
- `executor/`
- `storage/`
- `observability/`

O desenvolvimento principal deve ocorrer em branches Git; estes diretórios servem para preservar patches relevantes, comparação e documentação quando necessário.
