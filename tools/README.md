# Ferramentas auxiliares

- `build/`: scripts de compilação e configuração do ambiente.
- `benchmark/`: utilitários para execução/comparação de benchmarks.
- `profiling/`: coleta e tratamento de perfis de CPU, memória e I/O.

Ferramentas devem evitar dependências desnecessárias e registrar versões quando elas puderem alterar resultados.
